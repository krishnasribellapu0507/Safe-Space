# Safe Space Laptop App

The laptop build uses the same responsive Safe Space PWA as the website so the hackathon does not maintain a fake duplicate desktop client.

- Double-click `Safe Space Desktop.bat` for a dedicated Edge/Chrome app-style window.
- When the website is deployed over HTTPS, use the browser's **Install Safe Space** / **Install app** option to install it as a real PWA with its own Start/taskbar entry and app window.

This is intentionally described as a PWA/desktop experience, not a native Win32 executable.
