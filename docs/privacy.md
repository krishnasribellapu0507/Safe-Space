# Privacy and Consent

Safe Space is private by default. The product should help users understand changes in wellbeing without creating a feeling of hidden surveillance.

The mobile Consent Center controls journal intelligence, product analytics, location, voice transcription, notifications and support-personnel sharing. Journal intelligence, analytics, location, voice transcription and support sharing default off in the demo. Notifications are the only default-on convenience preference and must never include sensitive lock-screen details unless separately opted in.

Full journal entries are not part of the admin dashboard contract. Staff views receive explainable trend reasons, support requests and workflow status only. Location is requested only for an explicit nearby-support action. Trusted-contact actions require user initiation and confirmation.

Production data export and deletion should cover all user-owned tables and storage objects while preserving only legally required minimal audit records, with retention rules clearly disclosed.
