# Tools and Development Workflow

| Tool | What we used it for |
|---|---|
| VS Code | Editing Java, HTML, CSS, JavaScript, Node and Python files |
| Android SDK / Android Studio | SDK Platform 35, Build Tools, APK compilation support |
| JDK 17 | Gradle/Android Java compilation |
| Gradle | Android build automation |
| GitHub | Source control, code visibility and CI workflow |
| Node.js + Express | Prototype backend/API |
| Python | Explainable AI/trend reference scripts |
| SharedPreferences/localStorage | Local SIH prototype state |

### Local build sequence
`source code → Gradle → compile/package → app-debug.apk`.
