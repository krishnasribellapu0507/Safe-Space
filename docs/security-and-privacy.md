# Security, Privacy and Consent

- No production API keys are committed.
- Sensitive Android permissions are runtime/optional.
- Discreet mode and neutral-notification architecture are included.
- Journal data is not automatically shared with counsellors.
- AI output is labelled prototype decision support, not diagnosis.
- Production deployment should use encrypted storage, authenticated APIs, role-based access, audit logs, data-retention rules and formal consent governance.
