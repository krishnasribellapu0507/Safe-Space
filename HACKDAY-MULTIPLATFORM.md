# Safe Space — HACKDAY 1.0 Multi-platform Build

Safe Space now has four coordinated demo surfaces:

1. **Android mobile app** — native Java client and APK.
2. **Responsive web app** — `web-app/` with working mood, Journal, Calm, Insights, Companion, support and consent interactions.
3. **Laptop app experience** — install the web app as a PWA or launch it in Edge/Chrome app mode from `desktop/`.
4. **Authorized staff dashboard** — `admin-dashboard/` backed by the protected demo API.

## Demo sequence

Android/web user checks in → Safe Space explains lower mood / less sleep / higher stress against the personal baseline → user tries Calm or Journal → user requests professional support → authorized staff dashboard shows the support request without exposing journal text.
